The Product

One app, everything a night of pool needs

No login wall, no setup screen full of forms — the Setup Wizard gets a table playing in five plain-language steps, and everything from there is one tap away.

🎱

Live scoreboard

Tap +/− to track balls, points, or racks toward any game's target — 8-Ball, 9-Ball, Straight Pool, One Pocket, and more. Wins bank automatically and the next game starts itself, with milestone and "on the hill" pop-ups celebrating close finishes.

🧙

Setup Wizard

Five short steps — game type, players, who's playing vs. standby, rotation, review — take a table from cold start to Focus Mode, the distraction-free full-screen scoreboard, in under a minute.

🔁

Game Order rotations

Cycle automatically through a sequence of rules — one rack of 8-Ball, then three, then 9-Ball — with saved rotations that reload with one tap, exactly like saved player lists.

👥

Players & saved lists

Case-insensitive name matching, automatic capitalization, and duplicate-safe imports. Every distinct group you've ever played with is auto-saved and one click away — no manual bookkeeping.

🎨

Ten themes, real accessibility

Dark, bright, and high-contrast palettes — every accent color is computed per-theme to stay legible rather than assumed, so nothing ever renders as barely-readable text on a bright background.

🔊

Synthesized sound

Every tone is generated on the fly with the Web Audio API — no audio files to ship. Milestone wins get the full 30-note "Ode to Joy" theme, pitched low with a synthetic reverb tail.

Tournaments

Single elimination, double elimination, or round robin — run any night as a real event

One tap turns a regular session into a bracket. The bracket renders as a horizontal tree with connector lines so the whole shape is visible at a glance; round robin shows live standings plus every matchup at once.

  • Double elimination — the default: lose once, drop to a losers bracket, lose twice and you're out.
  • Single elimination — faster, no second chances.
  • Round robin — everyone plays everyone; best for casual groups.
  • Race-to-N sessions count as tournaments too — derived automatically and retroactively from existing game history, no separate data pool.
Stats & Ratings

Every player gets a career, not just a running score

Every player who has ever played on a device shows up on All Players — with sortable, filterable bar and cumulative-graph views, head-to-head records, and a click-to-inspect tooltip on any data point.

  • Elo-style ratings inspired by the scale FargoRate publishes (the system behind USA Pool League), updated automatically after every game — never editable by hand.
  • Team-aware — each side's average rating drives the win-probability calculation; the resulting change applies to every teammate.
  • Full history, not just a number — click any rating point to see exactly what happened: this player's change and every opponent's change from that same game.

Business Model

The monetization path isn't a slide — it's shipped code

Rather than pitch a hypothetical paywall, we built the real thing: a native in-app purchase flow on iOS, backed by Apple's StoreKit 2, gating a real premium feature today — with the freedom to expand what's gated as the product and audience grow.

1

Freemium core, native IAP unlock

The full scoring, stats, and tournament engine stays free on web — the way it's earned its users so far. On the native iOS app, a one-time Pro unlock (real Apple StoreKit 2 purchase, receipt-verified) removes the gate on premium features, starting with the Colorful Report export.

2

Rewarded-ad alternative

Players who'd rather not pay can unlock the same premium feature for a single session by watching a short rewarded ad — a familiar, low-friction mobile monetization pattern already wired into the same gate.

3

Expandable gate, not a one-off hack

The unlock check (requireProOrShowPaywall) wraps any feature in one line. Deciding what stays free vs. Pro is a product decision, not an engineering one — new premium features ship behind the same infrastructure with no rework.

4

Near-zero cost to serve

The web app is a static site with no backend, no database, and no per-user infrastructure cost — gross margin on the free tier is effectively 100%, so every converted user drops straight to the bottom line.
